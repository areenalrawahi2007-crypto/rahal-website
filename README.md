# موقع رحّال — النسخة الجديدة

## هيكل الملفات
- `index.html` — الصفحة الرئيسية (بطاقات الأقسام)
- `trips.html` — الرحلات المجهزة (حزم قابلة للتخصيص: إضافة/حذف عناصر)
- `equipment.html` — صفحة المعدات (مستقلة تماماً)
- `vehicles.html` — صفحة المركبات (مستقلة تماماً)
- `food.html` — صفحة التموين والطعام (مستقلة تماماً)
- `suppliers.html` — صفحة تسجيل مورد جديد
- `cart.html` — صفحة السلة (تعديل الكميات، الحذف، الإجمالي)
- `checkout.html` — صفحة إتمام الطلب: فاتورة شراء وفاتورة إيجار منفصلتان
- `contact.html` — صفحة تواصل معنا
- `terms.html` — الشروط والأحكام
- `privacy.html` — سياسة الخصوصية
- `styles.css` — كل التنسيقات
- `data.js` — **هنا تضيف/تعدّل المنتجات والرحلات والموردين** (ملف واحد يتحكم بكل الموقع)
- `app.js` — منطق السلة والبحث الحي والقائمة الجوالة

## كيف تضيف منتج جديد
افتح `data.js` ودزّ سطر جديد داخل مصفوفة `PRODUCTS`، مثال:
```js
{ id:'p7', category:'equipment', name:'اسم المنتج', desc:'وصف قصير', price:40, unit:'اليوم', emoji:'🎣', tags:['وسم1','وسم2'] }
```
- `category` لازم تكون: `equipment` أو `vehicles` أو `food`
- `emoji` هو الأيقونة اللي تظهر بالبطاقة (تقدر تستبدلها لاحقاً بصورة حقيقية)
- `tags` تستخدم بالبحث والفلاتر

## كيف تضيف رحلة مجهزة جديدة
دزّ عنصر جديد داخل مصفوفة `TRIPS` بـ`data.js`، وحط بس معرّفات منتجات موجودة أصلاً بـ`PRODUCTS`:
```js
{ id:'t5', name:'اسم الرحلة', days:2, emoji:'🏕️', desc:'وصف قصير', items:[{id:'e1', qty:1}, {id:'v1', qty:1}] }
```
العميل يقدر يعدّل الحزمة (يضيف/يحذف عناصر) من صفحة `trips.html` قبل ما يضيفها للسلة.

## البحث الحي
شريط البحث (بالهيدر وبقائمة الجوال) يفلتر تلقائياً بالاسم والوصف والوسوم `tags` لأي منتج بمجرد الكتابة، ويوديك مباشرة لصفحة القسم.

## السلة
- زر السلة العائم بزاوية الشاشة يظهر بكل الصفحات مع عدد القطع
- البيانات تُحفظ في متصفح الزائر (localStorage) — تشتغل تلقائياً بمجرد رفع الموقع على Vercel أو أي استضافة حقيقية
- **ملاحظة:** إذا فتحت الملفات داخل معاينة Claude فقط (بدون رفعها لموقع فعلي) قد لا تُحفظ السلة بين الصفحات؛ جرّبها بعد الرفع على Vercel أو بفتح الملفات مباشرة بالمتصفح لتأكيد عملها 100%.

## الصور
حالياً كل منتج يستخدم إيموجي كأيقونة سريعة. لاستبدالها بصور حقيقية:
1. حط صور المنتجات داخل مجلد جديد اسمه `assets/`
2. بدّل `emoji:'🤿'` بـ `image:'assets/mask.jpg'` في `data.js`
3. بدّل بالـ CSS/JS مكان عرض `${p.emoji}` إلى `<img src="${p.image}">`

## الرفع على GitHub + Vercel
الموقع HTML/CSS/JS ثابت بالكامل — ما فيه أي خطوة بناء (build). خطوات الرفع:

1. سوّي حساب مجاني على [github.com](https://github.com) لو ما عندك.
2. أنشئ مستودع (Repository) جديد فاضي — بدون README أو .gitignore (احنا مجهزينهم أصلاً).
3. من نفس مجلد المشروع، شغّل بالترمينال:
   ```
   git init
   git add .
   git commit -m "الموقع الأول"
   git branch -M main
   git remote add origin <رابط-المستودع-من-GitHub>
   git push -u origin main
   ```
4. سوّي حساب مجاني على [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub نفسه.
5. اضغط "Add New Project" واختر المستودع اللي رفعته — ما تحتاج تغيّر أي إعداد، اضغط "Deploy".
6. بعد دقيقة تقريبًا تحصل رابط حقيقي شغّال يقدر أي حد يفتحه من أي مكان.

أي تعديل تسويه بعدين على الملفات وتدزّه لنفس المستودع (`git add . && git commit -m "تعديل" && git push`) يظهر تلقائيًا على نفس الرابط خلال ثوانٍ.
